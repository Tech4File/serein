IMPORTANT

Security status

Web messages now use per-device ECDH→HKDF→AES-GCM and require explicit local fingerprint verification. Native Android and iOS device keys are protected with Android Keystore and iOS Keychain respectively. This implementation has not had independent cryptographic review; it does not provide forward secrecy or automated key rotation/recovery. Do not use it for high-risk communications until those gaps are addressed.

DANGER ZONE

Delete account

This permanently deletes this account, credentials, devices, keys, sessions, and server-side data. Contacts keep a read-only archived copy of their existing chat under this account’s immutable ID. Your browser’s account-specific local data is removed after confirmation.

Exported backup files stored elsewhere cannot be erased by this service. A newly registered account has a new identity and cannot restore or attach the old chat through Serein.

Storage & data

Create a full snapshot encrypted locally with a stable, account-specific key derived locally from the authenticated account ID, then download it as a Serein backup file. The account ID is not written to the cleartext file header; the server does not receive the backup file.

What is included?All locally stored message records and media references. Media files themselves are not currently included. Older backups are not overwritten; each download gets a new timestamped name. New backups restore by signing into the same account. Legacy version 1 files still require the password used when they were created.
Web limitationsAutomatic scheduling, cloud-provider selection, and mobile-assisted history sync are not wired yet. Browser downloads are user-managed; this page cannot promise background backups while closed.

    Only requests addressed to your account can be accepted. Ignoring or declining does not notify the sender.

    PRIVACY

    Blocked accounts

    Blocking removes the contact link for both accounts and stops requests, message delivery, and transfers. Existing server ciphertext history is retained.
