    ADDRESS BOOK

    Request a connection

    Send a private request by username or verified email. The other person must accept before either of you appears in the other's contacts. The API gives the same response whether an address is eligible.

    CONNECTIONS

    Contact requests

    Only requests addressed to your account can be accepted. Ignoring or declining does not notify the sender.

    PRIVACY

    Blocked accounts

    Blocking removes the contact link for both accounts and stops requests, message delivery, and transfers. Existing server ciphertext history is retained.
