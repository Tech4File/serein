SEREIN · SECURITY

Security status

Not suitable for sensitive conversations

What is currently protected

The web client encrypts message text with AES-GCM before sending it to the relay. The passphrase is shared by conversation participants; this key setup is not a vetted identity protocol and has not received an independent security audit. The relay can still observe routing metadata.

  • There is no verified device identity, ratchet, or forward secrecy.
  • Room and device identifiers are routing metadata, not authentication credentials.
  • The Android and iOS clients provide account access, but their native message delivery and encryption are not implemented.
  • HTTPS protects network transport when correctly configured; it is distinct from end-to-end encryption.

Do not use this service for sensitive communications. A production release requires a maintained, audited end-to-end protocol, secure device-key handling, authenticated sessions, TLS, rate limits, bounded retention, and independent review.
