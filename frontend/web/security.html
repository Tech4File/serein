Security notes

This is a development starter

The web demo encrypts message text in the browser with AES-GCM and sends ciphertext to the relay. It does not implement a vetted identity protocol, account authentication, device verification, ratchet, forward secrecy, or metadata protection. Room and device labels are routing metadata, not credentials. The Android and iOS folders are starter shells and are not interoperable encrypted clients yet.

Do not use this project for sensitive communications or expose its development server directly to the internet. For production, integrate a maintained audited end-to-end protocol, secure device key storage, authenticated sessions, TLS, rate limits, bounded message retention, and independent security review.
