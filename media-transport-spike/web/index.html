RESEARCH MILESTONE · DATAGRAM ECHO ONLY

WebTransport connectivity check

This checks whether a browser can establish an HTTP/3 WebTransport session and echo short datagrams to the Rust service. It is not a messenger, call stack, media encoder, relay, or E2EE test.

Not connected

Requires a browser with WebTransport support and a TLS certificate it trusts. The server must be reachable over UDP. Do not use the echo server with real user data.
